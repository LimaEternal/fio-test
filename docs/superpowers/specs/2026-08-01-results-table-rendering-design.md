# Дизайн отрисовки таблиц результатов

## Цель

Сделать консольные результаты удобнее для чтения: каждый накопитель должен иметь собственную шапку и самостоятельный рамочный блок, при этом блоки разных накопителей выводятся подряд без пустых строк.

## Компоновка

- Для каждого диска строится отдельная таблица с колонками `№`, `Накопитель` и `Результаты тестирования накопителя (FIO)`.
- Собственная шапка повторяется для каждого диска.
- Под шапкой слева показывается паспорт диска: устройство, модель, интерфейс, серийный номер, слот и размер.
- Справа показывается вложенная таблица тестов в неизменном порядке: `seq_read`, `seq_write`, `rand_read`, `rand_write`.
- Шапка вложенной таблицы имеет отчётливую замкнутую рамку и отделена от строк результатов.
- Таблицы накопителей следуют непосредственно друг за другом. Значение промежутка задаётся централизованно и по умолчанию равно нулю.

## Цвет и оформление

- Цветовая разметка применяется только к статусам: зелёный `done`, красный `undone`.
- Номер диска, паспорт, заголовки, значения и рамки используют стандартный цвет терминала.
- Формат чисел, единицы измерения и порядок тестов не меняются.

## Архитектура

Отрисовка переносится из `fio-test.py` в `utils/table_renderer.py`. Модуль разделяется на небольшие функции с одной ответственностью:

- форматирование статуса;
- построение паспорта диска;
- построение вложенной таблицы тестов;
- построение отдельного блока диска;
- объединение блоков без промежутка.

Точка входа `fio-test.py` продолжает отвечать за запуск тестов и подготовку данных, затем передаёт `disks` и `results` модулю отрисовки. Типы рамок и промежуток между блоками хранятся рядом с кодом представления, чтобы оформление можно было менять без изменения логики тестирования.

## Проверка

Автоматические тесты рендерят таблицы Rich в текстовую консоль фиксированной ширины и проверяют:

- у каждого из двух дисков есть собственная шапка;
- оба диска представлены самостоятельными рамочными блоками;
- между соседними блоками нет пустой строки;
- сведения о дисках и результаты не потеряны;
- разметка цвета применяется только к `done` и `undone`.

Изменение не затрагивает обнаружение дисков, запуск `fio`, расчёт результатов и Markdown-отчёт.
